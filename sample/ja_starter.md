# Japanese starter set

Eighteen beginner exercises (levels 1–3), one or more of every exercise type
of the Japanese track, written from scratch for this project. Import them from
the **Studio** tab to try the app without spending tokens.

Text outside a `## <exercise_type>` block, like this paragraph, is ignored.
The front matter above sets the default difficulty; blocks override it.

## kanji_reading
topics: self_introduction, school
sentence: わたしは 学生です。
translation: Sono uno studente.
focus: 学生
- [x] がくせい
- [ ] がっせい
- [ ] がくせ
- [ ] かくせい
explanation: 学生（がくせい） = studente. Niente っ piccola, e la い finale si legge.
